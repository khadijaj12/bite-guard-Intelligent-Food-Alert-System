# Food Alert System

Food Alert System is a consumer safety application designed to help users make informed dietary decisions by analyzing food-related information and identifying potential health concerns before consumption.

The system focuses on detecting ingredients that may conflict with allergies, dietary restrictions, or individual health requirements. The project was built with the idea that technology should assist users in making safer and healthier everyday decisions.

## Features

* Ingredient analysis system
* Detection of allergy-triggering food components
* Dietary restriction awareness
* Health-conscious food recommendation logic

## Technologies Used

* React + TypeScript (Vite)
* Tailwind CSS + shadcn/ui
* Supabase
* Rule-based ingredient and allergy checks

## Goal

To create an intelligent assistant capable of improving consumer awareness and food safety through automated analysis of food-related information.

## Running it locally

```bash
cp .env.example .env   # then fill in your Supabase URL, project ID and publishable key
npm install
npm run dev
```
